# ゆりかごから墓場まで：ひとの生涯に寄りそうAIパートナーのSFプロトタイピングと認知科学的展開

**URL:** https://toyotafrc.github.io/JCSS26OS-AISF-Proj/

AIパートナーは本当に"善い社会"をもたらすのか。物語を先につくり、そこから研究の問いを立て直します。

このプロジェクトは**日本認知科学会第43回大会 オーガナイズドセッション**にて報告されます。
